# Pinned to the exact versions proven working locally, so a cloud deploy
# (Render/Fly) installs the SAME versions and can't pull a newer breaking
# release. This is what caused the first Render failure: `mcp` was unpinned,
# pip installed a newer version whose API had moved (streamablehttp_client),
# and it crashed the whole backend at import. Pin everything.
#
# NOTE on Python version: this project targets Python 3.11. Render picks its
# own Python unless told otherwise — set the PYTHON_VERSION env var to 3.11.x
# (e.g. 3.11.9) in the Render dashboard. 3.14 will fail to build several of
# these wheels (numpy/scipy/webrtcvad).
